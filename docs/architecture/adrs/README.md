# Architecture Decision Records

This directory contains durable, solution-specific decisions for the
CanadaLogin Partner Portal.

[Return to the solution architecture index](../README.md).

| ID | Title | Status |
|---|---|---|
| [ADR-001](adr-001-bff-and-server-session-authority.md) | BFF and Server Session Authority | Accepted |
| [ADR-002](adr-002-api-wire-and-error-contract.md) | API Wire and Error Contract | Proposed |
| [ADR-003](adr-003-casbin-authorization-model.md) | Casbin Authorization Model | Proposed |

Statuses:

- `Proposed` records a direction or unresolved choice and is not binding.
- `Accepted` records a decision the project intends to preserve.
- `Superseded` points to the decision that replaced it.
- `Deprecated` records a decision that is no longer recommended.

ADR identifiers are sequential and are never reused or renumbered.

For future ADRs, assign identifiers using `STD-001: Document Identifiers`, use
`TPL-006: ADR Template`, and reference shared Delorean guidance by stable ID and
title.
