# Standards Templates

Use these templates when adding or updating architecture and engineering standards.

- [TPL-001: Standard Template](tpl-001-standard-template.md) provides the structure for a new standard.
- [TPL-002: Standards Index Entry Template](tpl-002-standards-index-entry-template.md) provides the table row shape used by the standards README.
- [TPL-003: Standards Impact Template](tpl-003-standards-impact-template.md) provides a compact way to record how a change affects standards.
