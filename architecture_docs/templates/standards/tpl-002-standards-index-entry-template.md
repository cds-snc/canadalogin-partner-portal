# TPL-002: Standards Index Entry Template

Type: Template
Status: Active

Use this table row shape when adding a standard to `docs/standards/README.md`.

```markdown
| STD-000 | [<Standard name>](std-000-standard-name.md) | Use when <decision, system area, or review concern applies>. |
```

Keep the "when to use it" text short and action-oriented.
