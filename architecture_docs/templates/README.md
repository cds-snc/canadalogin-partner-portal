# Templates

Use these templates when creating reusable architecture guidance or project-level architecture records.

Templates in this repo should stay generic. They should help teams write standards, patterns, reference architectures, architecture decisions, design decisions, and verification notes without introducing project-specific process or implementation details.

Schema contracts may support templates when a reusable decision or architecture
review evidence shape needs machine-readable fields. Keep those contracts
focused on shared guidance. Generated evidence bundles, waiver records, gate
records, and local validation output belong in `delorean_template`; project
repos store their local records and generated evidence.
