# GC-WEB-002: Canada.ca Design, Federal Identity, And Page Shell

Type: Control
Status: Active
Source: Government of Canada

## Intent

Confirm that public-facing web applications follow the applicable Canada.ca
design, external-facing website, and federal identity expectations.

## Required Outcome

Public-facing web applications follow the applicable Canada.ca design,
external-facing website, and federal identity requirements unless an approved
exception applies.

## Assessment

Confirm the application:

- uses approved Government of Canada page shell patterns for header, footer,
  navigation, language toggle, main content, and date modified where required
- uses GC Design System, GCWeb, WET, or another approved project design-system
  path intentionally
- keeps official symbols, header, footer, and mandatory links aligned with the
  selected scope
- uses task-oriented page and navigation patterns for service workflows
- records any design-system or page-shell exception before implementation

## Evidence Examples

- selected page pattern decision
- desktop and mobile screenshots
- design-system checklist
- custom UI exception record
