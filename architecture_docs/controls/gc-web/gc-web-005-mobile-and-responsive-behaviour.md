# GC-WEB-005: Mobile And Responsive Behaviour

Type: Control
Status: Active
Source: Government of Canada

## Intent

Confirm core tasks are usable across supported screen sizes, zoom levels, and
input methods.

## Required Outcome

The application is usable across supported screen sizes, zoom levels, and input
methods.

## Assessment

Confirm the application:

- uses responsive layouts for small, medium, and large screens
- keeps all core tasks available without horizontal scrolling or clipped content
- supports touch, keyboard, pointer, and assistive technology interaction where
  applicable
- avoids fixed layout values that break mobile or zoomed views
- verifies meaningful UI changes at mobile and desktop widths

## Evidence Examples

- mobile screenshot
- desktop screenshot
- zoomed or narrow viewport check
- responsive layout review note
