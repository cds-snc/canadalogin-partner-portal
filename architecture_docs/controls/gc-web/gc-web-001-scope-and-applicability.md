# GC-WEB-001: Scope And Applicability

Type: Control
Status: Active
Source: Government of Canada

## Intent

Identify the application type, audience, owner, and applicable Government of
Canada policy context before selecting a baseline or release path.

## Required Outcome

The application identifies whether it is public-facing, internal-facing,
partner-facing, administrative, or a mixed service.

## Assessment

Record:

- target users and service owner
- public, internal, partner, or administrative audience
- whether the app is a website, web application, mobile web application, API, or
  supporting admin tool
- whether it uses Canada.ca, gc.ca, departmental domains, or another approved
  access path
- whether the service handles rights, benefits, high-volume transactions, or
  other high-priority public services
- applicable project, departmental, or program-specific policy requirements

## Evidence Examples

- architecture note
- service overview
- release plan
- standards impact block
