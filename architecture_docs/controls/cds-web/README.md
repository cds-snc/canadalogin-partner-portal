# CDS Web Controls

Use this folder for CDS-specific web application controls.

Use the `CDS-WEB` namespace when a control comes from CDS delivery expectations,
team standards, program policy, or local operating practice rather than a
Government of Canada-wide source.

Examples of future controls could include CDS-specific service design review,
support readiness, delivery health, product measurement, or operational
ownership expectations. Add those only when the source and expected evidence are
clear.

New controls should follow
[TPL-012: Control Template](../../templates/controls/tpl-012-control-template.md)
and be added to [the control catalog](../catalog.yml).
