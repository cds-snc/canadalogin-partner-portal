# Delorean Local Files

This folder holds Delorean process records and record templates for this solution.

Use it for reviewed evidence, approval and waiver payload templates, and examples that show how Delorean process records should look.

Use [config.yaml](config.yaml) to set the repo's Delorean adoption level. Agents
read that file before deciding which skills to invoke and which outputs are
required.

Use [docs/repo-guidance/where-things-go.md](../docs/repo-guidance/where-things-go.md) for local routing.
