# Templates

Store small templates for Delorean process records.

Use this folder for approval responses, waivers, change-state records, and other local records that support the Delorean way of working.

Do not copy core process documents here.

Starter templates:

- [delorean/templates/change-state-template.yaml](change-state-template.yaml)
- [delorean/templates/approval-response-template.md](approval-response-template.md)
- [delorean/templates/waiver-template.md](waiver-template.md)

Use `change-state-template.yaml` to create `delorean/evidence/<change-id>/change-state.yaml` for a real change. It records status and links, not requirements.

OpenSpec remains the home for requirements, scenarios, proposals, design notes, and tasks.
